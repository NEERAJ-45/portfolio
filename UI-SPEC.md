## Visual Contract — Vertical Journey

### Canvas & Layout

| Property | Value |
|----------|-------|
| Breakpoint | max-width: 768px |
| Section height | `height: auto; padding: 100px 0 50px` (no pinning — content scrolls naturally) |
| Container | Full-width column flex, padding 0 6vw |
| Scroll trigger | `start: 'top 80%'`, `end: 'bottom 20%'`, scrub: 0.6 |

### SVG Road Path

| Property | Value |
|----------|-------|
| Shape | **S-curve** winding vertically (zigzag) |
| ViewBox | `0 0 400 800` (portrait orientation) |
| Path style | 2.5px stroke, dashed (12 14), color `#c5ff7c` at 85% opacity |
| Background glow | 20px wide at `rgba(255, 255, 255, 0.08)` |
| Width | 100% of viewport, `preserveAspectRatio: none` |
| Height | 60% of road-pin container |
| Path data | Cubic bezier: center → right → center → left → center (S-curve top to bottom) |

### Rocket / Spaceship

| Property | Value |
|----------|-------|
| Orientation | **Follows path tangent** (auto-rotates via atan2 calculation) |
| Scale | 0.7× of desktop (smaller viewport) |
| Starting position | Top of path (hidden initially, autoAlpha transitions in) |
| Trigger | ScrollTrigger with scrub matching desktop behavior |

### Sky & Atmospheric Transition

| Property | Value |
|----------|-------|
| Sky gradient | Same sunset → night gradient as desktop |
| Sun position | Top 25%, 60px diameter (scaled from 140px) |
| Moon position | Top 18%, 50px diameter (scaled from 100px) |
| Transition timing | Sun fades out in first 30% of scroll, moon rises 15-50% |
| Nebula | Single radial glow at center-top, 60vw, blur 40px |

### Stars

| Property | Value |
|----------|-------|
| Count | 50 (reduced from 90 for mobile perf) |
| Distribution | inset 0 0 40% 0 (upper sky area) |
| Animation | Opacity 0→1, scale 1→1.3 during sky→night transition |
| Style | Random 1-2.5px dots, random opacity 0.2-1.0 |

### Hills / Terrain

| Property | Value |
|----------|-------|
| Visibility | Hidden (not enough vertical space — milestones provide context) |

### Milestones

| Property | Value |
|----------|-------|
| Layout | **Alternating sides** — left side for milestones 2 & 4, right side for 1 & 3 |
| Positioned along path | True — computed via `path.getPointAtLength()` same as desktop |
| Card width | `calc(50vw - 32px)` — fits within half the viewport |
| Card height | Auto (content-driven) |
| Station icon | 36×36px SVGs (scaled from 50×50) |
| Card design | Frosted glass (same as desktop): `bg rgba(8,10,16,0.75)`, `backdrop-filter blur(12px)`, border `1px solid var(--panel-border)` |
| Transition | Scale 1→1.15 on hover, window icons highlight green when rocket passes |

### Road Progress Label

| Property | Value |
|----------|-------|
| Position | Top of section, relative flow |
| Copy | "03 · Voyage Timeline — scroll to voyage" |
| Style | JetBrains Mono, 0.75rem, uppercase, letter-spacing 0.15em |

## Animation Timing (Scrub)

| Element | Duration (relative) | Easing |
|---------|-------------------|--------|
| Rocket path traversal | 2.0 | none (linear stretch) |
| Sky sunset → night | 2.0 | none |
| Hill fills darken | 2.0 | none |
| Stars opacity 0→1 | 2.0 | none |
| Sun fade out | 0.9 | none |
| Moon fade in (offset 0.6) | 1.0 | none |
| Road stroke glow | 2.0 | none |
| Milestone highlight (each) | 0.5 | power2.out / power2.in |
| House window glow (each) | 0.4 | power2.out |

All durations are relative within the timeline (total scroll range maps to total timeline duration).
